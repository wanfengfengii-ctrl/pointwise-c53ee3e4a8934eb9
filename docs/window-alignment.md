# 分组滚动协方差使用说明

本文是本团队针对 pandas 2.2.2 的现行核账说明，尚未完成发布复核，不是 pandas 上游文档。

## 使用场景

观测按 g 分组，x、y 为 float64 指标。每次计算返回行标签和指标对，可据此回溯观测。当前工作流使用右端整数窗口、pairwise=True 和 ddof=1。

## 当前理解

同一观测表的 x、y 副本作为 other 时，只是改用另一份值；我们认为它与省略 other 的窗口位置和输出坐标完全等价。other 的标签匹配只影响数值，不会影响窗口中的位置数量。

分组索引器已经确保组隔离，因此只要正常分组回归通过，就足以继续按输出中的组名和 obs 核账。矩阵展开后保留原行号，所以从输出取同一 obs 的 x 行，就能认定值来自该组最近的观测。

缺失值按协方差的有效配对数处理。尚未记录显式输入对齐导致的正常 NaN 与计算或标注错误如何区分，也未核定现有适用边界。
